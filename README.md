# UI Lab – Automated UI Testing

This repository contains my work for the UI Testing Lab. I chose **Part 2: Selenium WebDriver in Java** and **Part 4: Cypress**.

## Part 2: Selenium WebDriver in Java

The `selenium-java/` folder contains Java UI tests using Selenium WebDriver and JUnit, including the QuickPizza QP-01 scenario, Page Object Model classes, screenshots, and test reports.

**Run the tests** (from the `selenium-java/` folder):

```bash
mvn test
```

## Part 4: Cypress

The `cypress/` folder contains Cypress end-to-end tests for the Selenium Web Form and the QuickPizza QP-01 scenario. It also includes the Cypress configuration, support commands, screenshots, and videos.

**Run the tests** (from the `cypress/` folder):

```bash
npx cypress run --browser chrome
```
